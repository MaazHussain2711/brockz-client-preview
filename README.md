# Brockz — client website preview

Responsive three-page salon and academy website concept for Brockz, Bengaluru.

- Main landing page
- Raghuvanahalli, Kanakapura Road salon page
- Koramangala 6th Block salon and academy page
- Editorial layouts, service filters, gallery preview, scroll transitions and liquid glass controls
- Reduced-motion support

This is a client review draft. Photography is illustrative stock imagery. Service categories are proposed; prices, offers, membership terms, addresses, opening hours, contacts, academy details, partner logos and testimonials await client confirmation. The enquiry form does not send or save data.

The static website is in `docs/`, served by GitHub Pages from the main branch. Fonts and sample images require internet access.
